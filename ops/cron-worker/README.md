# Cloudflare 워커 `chzzk-checker` (1분마다 서버 깨우기)

## 무엇이 바뀌었나
예전 워커는 치지직 상태를 보고 **Firestore 에 직접** 저장했어요(방송 상태, 방송 끝나면 기록 만들기, 유튜브 편집본 붙이기).
그런데 로그인 없이 쓰는 방식이라, 데이터베이스 보안 규칙을 "관리자만 쓰기"로 잠근 뒤부터는 **저장이 전부 거절**되고 있었어요.
기록도 지금 사이트가 읽지 않는 위치(`logs_by_month/{월}/logs/…`)에 쓰고 있었고요.

이제는:
- 실제 작업은 사이트 서버(`/api/notifications/tick`)가 관리자 권한으로 해요.
  - 방송 상태 갱신, 방송 시작 알림, 유력 시간 알림
  - **방송이 끝나면 방송 기록 자동 생성** (예전 워커 기능. 관리자가 이미 기록했으면 건너뜀, 관리자 > 시스템 > 자동 시스템에서 끄기 가능)
- 워커는 매분 서버를 불러 주기만 해요. 하루 두 번은 유튜브 목록을 새로 받게 해요.
- 유튜브 편집본 자동 붙이기(게임 이름으로 추측)는 같은 게임을 여러 날 하면 엉뚱한 날에 붙어서 옮기지 않았어요. 관리자 > 연동 화면에서 확인하며 붙이는 게 정확해요.

## 다시 배포하기 (한 번만)
1. 예전 워커 폴더(`wrangler.jsonc` 와 `src/index.js` 가 있는 곳)에 이 폴더의 두 파일을 덮어써요.
2. 그 폴더에서 `npx wrangler deploy`
3. 브라우저에서 워커 주소(예: `https://chzzk-checker.<계정>.workers.dev`)를 열어 `"status": 200` 이 보이면 끝.
4. 관리자 > 시스템 > 자동 시스템의 "최근 실행 출처"에 `Cloudflare` 가 1분 간격으로 보이면 정상이에요.

`YOUTUBE_API_KEY` 같은 워커 비밀값은 이제 필요 없어요(지워도 돼요).
